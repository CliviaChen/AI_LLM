# 对话记录

本目录保存开发「控制室」工作台时的 DeepSeek Harness 会话转写，用于换机阅读、复盘和继续开发。

## 文件

- `2026-11-21-control-room.md` — 完整转写：每轮用户需求、助手的最终回复、工具调用名称与简短参数。

转写不包含：系统提示、运行时上下文（工作区/技能目录）、模型的推理过程、工具输出全文。因此它是"可读版"，不是可回放的会话日志。

## 到另一台电脑上怎么用

**只是想继续开发工作台**：克隆仓库后在 DSH 的 Plugins → Add plugin 里选择 `control-room` 目录即可，不需要这份对话记录。

**想接着这次对话的思路往下做**：直接读 `2026-11-21-control-room.md`，里面记录了需求演进、选型理由、取舍和已知限制；把它当作项目上下文交给新的会话也够用。

**想在新机器上恢复这次 DSH 会话本身**：需要原始会话文件 `session.v4.jsonl.zstd`（本次没有随仓库提交）。在旧机器上从 DSH 会话菜单导出会话日志，放到新机器的 `~/.dsh/sessions/<按工作区编码的目录>/session-<id>/` 下，即可在对应工作区看到这次会话。注意会话里记录了旧机器的绝对路径，恢复后工作区路径可能需要重新绑定。
