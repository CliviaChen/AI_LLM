# PRD · 控制室 v1（学生项目驾驶舱）

> 依据 `docs/product-plan.md` 收敛为可执行需求 · 目标版本：0.5.0

## 1. Summary

控制室 v1 把"项目卡片墙"升级为**能推进工作的驾驶舱**：卡片区分「空闲 / 运行中 / 等你确认」，顶部给出「现在该做」的三张卡；**点卡片不再直接进入对话**，而是打开项目详情——概览、看板、任务、会话四个视图，需要时再从详情里进入对话。面向每周都要交付成果的金融专业本科生，解决"每次开工都要花十几分钟找回上下文"的问题。

## 2. Background

现状：三列卡片列出全部工作区，运行中的项目以荧光绿硬投影脉冲提示。问题在于卡片是**死链**——点进去只有对话，学生想看的"这周做了几次、任务还剩几件、哪个会话卡住了"都不在页面上。

一次用户反馈确认了方向：金融模板不好用（模板给的是提示词，学生真正缺的是**项目状态**），因此 v1 删去模板，把预算投到详情视图。

## 3. Objective

让学生在同一周投入下推进更多项目。

**Key Results（beta 4 周，相对基线）**

- KR1 每周有效推进项目数（WPA）+30%。
- KR2「打开控制室 → 进入某个项目」中位时间 ≤ 10 秒。
- KR3 详情页任务清单的使用率 ≥ 50%（至少新增 1 条任务）。

## 4. Market Segments

按任务划分（不按人口属性）：

- **S1 课程交付型**（主）：每周 1–2 份报告/作业；可用时间被课表切成 30–90 分钟；不会为工具付费。
- **S2 竞赛/科研型**（次）：1–3 个月长周期，需复现；首版只做单人。

约束：Windows 笔记本为主；数据敏感；第一周不省时间就会被弃用。

## 5. Value Propositions

### S1（主）

- **Who**：金融/经济专业本科生，每周有必须交付的作业或案例报告。
- **Why**：他们要把材料和数据变成有结论的报告。卡点不在写，在**开工**——不知道上次做到哪、先做哪个。
- **What before**：文件管理器 + 微信传的材料 + 一堆标签页 + 手写待办；长任务跑着跑着开始刷手机。
- **How**：一张卡 = 一个项目；点进去就是它的驾驶舱（进度、任务、会话），顶部焦点条直接说"现在做这个"，等待中的会话标成"等你确认"。
- **What after**：从打开电脑到开始产出 < 1 分钟；等待时间转成处理另一张卡；期末能按项目回溯。
- **Alternatives**：Notion/飞书（要手工维护，记录与工作现场分离）、番茄钟（只管时间）、文件夹+Excel（零结构）、DSH 侧边栏（能列会话，不表达项目阶段）。**我们赢在工作现场同屏**。

**陈述**：给每周都要交作业的金融学生，控制室把"找回上下文"降到一次点击，让等待中的长任务变成可见、可切换的状态。

### S2（次，精简）

- **Who/Why**：竞赛与科研学生，怕"跑完才发现参数错"和"复现不出来"。
- **What before**：脚本散落、图命名混乱、版本靠复制文件夹。
- **How**：详情页记录阶段与任务；会话列表可按时间回溯。
- **What after**：随时能回答"到哪一步、下一步是什么、上次跑在哪"。

## 6. Solution

### 6.1 关键流程

1. 打开控制室 → 焦点条给出 ≤3 张「现在该做」的卡（等你确认 > 今日/明日截止 > 本周截止 > 运行中 > 本周动过）。
2. **点卡片 → 进入项目详情**（不启动对话）。
3. 详情内切换四个视图：**概览 / 看板 / 任务 / 会话**。
4. 需要 AI 时点「进入对话」；点会话列表里的某条，直接打开那次会话。
5. 「← 返回」回到卡片墙。

### 6.2 功能（v1 must-have）

| # | 功能 | 说明 | 验收要点 |
|---|---|---|---|
| F1 | 三态卡片 | 空闲 / 运行中 / 等你确认（审批、计划待审、待回答） | 状态来自宿主；缺失时降级为空闲 |
| F2 | 今日焦点条 | 最多 3 张，带"为什么是它"的原因 | 无候选不渲染 |
| F3 | 项目详情 | 点卡片进入详情，不再直接进对话；有返回与「进入对话」 | 返回后卡片墙状态不丢 |
| F4 | 看板 | 会话数、任务完成度、距截止、最近活动 + 14 天活动条 | 数据全部来自宿主与本地任务 |
| F5 | 任务 | 新增 / 完成 / 删除，带进度条 | 刷新后仍在 |
| F6 | 会话列表 | 该项目所有会话，点击打开对应会话 | 打开的是那一条，不是默认会话 |
| F7 | 项目元数据 | 阶段、截止、下一步 | 可留空；卡片上回显阶段与截止 |
| F8 | 首次引导 | 一行说明，可关闭并记住 | 不再自动出现 |

### 6.3 非功能

- 视觉延续孟菲斯硬边：2px 描边、零模糊硬投影、荧光绿=需要你、方形卡片、无倾斜。
- 无障碍：全部可键盘操作；焦点可见；状态不只靠颜色；`prefers-reduced-motion` 关闭脉冲与位移。
- 隐私：项目元数据与任务只存 `localStorage`，不上传。

### 6.4 假设与未决

- A1 学生愿意为项目填一个截止日期（待访谈验证）。
- A2 `pendingInteraction` 三种 kind 足以覆盖"需要你"。
- A3 详情页确实比直接进对话更少打断（待对照测量）。
- 未决：元数据是否改为宿主侧配置（跨设备）。

### 6.6 v1.1 增量（已实现）

| # | 功能 | 说明 | 验收要点 |
|---|---|---|---|
| F9 | 右键菜单 | 卡片右键：归档 / 隐藏 / 会话收藏与备注 | 归档或隐藏后卡片移出网格与焦点条；网格下方一行可恢复并标记 |
| F10 | 会话收藏与备注 | 会话行可收藏（★）并写一句备注 | 与项目元数据同存本地；刷新后仍在 |
| F11 | 时钟 | 右上角：时:分为最大字号，日期与系统星期为小号大写 | 分钟自走；星期随系统语言 |
| F12 | 记录 | 左下角抽屉：日 / 周 / 月切换，已完成项目数、会话数、最活跃时段、Token | 完成数按 `doneAt` 落到窗口内；Token 取不到显示 — |
| F13 | 报告导出 | 记录面板右上角：复制 / 下载 Markdown | 内容与面板一致；文件名为 `control-room-<scale>-<date>.md` |
| F14 | 阶段配色 | 未选择/起步/进行/待复核/已交付 = 中性/青/琥珀/洋红/墨黑；卡片底色 13% 着色 + 加粗实心色块 | 与"运行中"的荧光绿脉冲区分：荧光绿不参与阶段配色 |
| F15 | Token 用量（Host 路线） | Token 磁贴可点击；Host 半边读会话日志 + 账号余额，注册 `GET /api/control-room-usage` | 净消耗（input+output）与总消耗（含缓存）都显示；非 owner Peer 返回 403；读不到明确说明 |
| F16 | 最活跃时段 | 按 token（净消耗）排名，随尺度变化：日=最忙的连续 3 小时、周=最忙的一天、月=最忙的一周 | 无对应小时/天/周数据时**整块移除**，不留 `—` |
| F17 | 工作区重命名 | 卡片右键 →「重命名工作区」→ 独立弹窗输入 → 确定 | 写入真实工作区记录（`workspaceController.rename`），**侧边栏同步改名**；空名/重名有错误提示 |

**Token 的真实约束**：账号接口（`deepseekAccount`）只有余额，没有用量；真实 token 数在**会话日志**里（`data.message.usage`）。因此 F15 由 Host 半边读日志并求和，两种口径都返回：`net = input+output`、`total = totalTokens（含缓存）`。数据经由 Connection 的 exact Fetch 路由 `GET /api/control-room-usage` 提供，框架对非 owner Peer 直接 403。Host 改动不热重载，**在 Plugins 里关开一次插件行即可加载**（无需重启应用），激活状态记录在 `<dsh home>/control-room-host.json`。**不估算。**

### 6.7 候选功能（未排期，按可行性排序）

| 功能 | 价值 | 可行性 |
|---|---|---|
| 全局筛选（按阶段 / 逾期 / 等待中） | 项目多了才需要 | 可行，纯前端 |
| 任务跨项目聚合「今天要做的」 | 减少逐卡翻看 | 可行，本地任务 + 焦点逻辑 |
| 周报导出（Markdown 复制/下载） | 期末复盘、给老师看进度 | 可行，本地汇总 |
| 键盘导航（Esc 返回、1–4 切视图、N 新任务） | 高频用户提速 | 可行 |
| 项目归档 / 隐藏 | 卡片墙减噪 | 可行，本地标记 |
| 会话收藏与备注 | 找到"那次跑通的" | 可行，本地存储 |
| 项目模板（真正生成目录骨架） | 替代已删掉的提示词模板 | **需宿主文件 API**，当前插件拿不到 |
| 时间与 token 投入统计 | 真实的效率度量 | **需宿主提供指标**，当前拿不到 |
| DDL 前一天提醒 | 防逾期 | **需通知能力**，当前没有 |

## 7. Release

**v1（已完成）**：F1–F8，单人、本地存储。

**v1.1（已完成）**：F9–F13 —— 右键菜单、会话收藏与备注、时钟、记录抽屉与 Markdown 导出。

**v1.2**：全局筛选、任务聚合、键盘导航。

**不做**：记账理财、课程表、团队协作、云同步与账号、替学生写作业。

## 8. 风险

| 风险 | 对策 |
|---|---|
| 详情页变成"多一层点击" | 详情首屏即给「进入对话」；焦点条一键直达详情 |
| 变成又一个待办清单 | 任务与项目绑定，且卡片墙只显示状态不显示全部任务 |
| 本地存储丢失 | 明确告知为本地数据；v1.1 评估宿主侧存储 |
| 看板数字没意义 | 只用可解释的四个指标，不做花哨图表 |
